## ai服务器租用报价由哪几项组成？

报价通常由 GPU 实例费、云盘和带宽三块组成，其中 GPU 型号和计费周期对总价影响最大。

GPU 型号和显存是第一变量。T4、P4、P100、V100-16G、V100-32G、A10 这些卡在公开报价里都能找到，显存从 8G 到 32G，月价从一千五到九千多。同样是 A10，32核188G 的 GN7i 月付 3213.99 元，8核31G 的 SGN7i 只要 1503.50 元，区别是后者只分到 1/3 张 A10。

整卡和分片是第二个容易忽略的点。分片虚拟化把一张物理卡切给多个实例，价格低，显存和算力也按比例缩水。轻量推理、远程图形设计这类任务够用，要大显存训练就不合适。

CPU 和内存的配比也会拉开价差。GPU 实例不是只卖卡，CPU 核数、内存容量、是否支持多卡都在价格里。选型时别只盯着 GPU 型号，内存不够，数据加载先卡住。

计费周期决定单价。按小时、月付、年付三种方式在公开页面上都有，年付折扣因实例而异，后文会单独算。

> 报价页上的“元/月”一般只是 GPU 实例本身的价格。系统盘、数据盘、公网带宽往往另算，做推理服务对外提供 API 时，带宽账单可能比想象中显眼。
